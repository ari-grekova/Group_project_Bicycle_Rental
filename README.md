# Group_project_Bicycle_Rental
group task Bicycle Rental

Іменники
місто, станція, велосипед, тип велосипеда(звичайний / електричний), номер, клієнт, ім'я, баланс, рахунок, хвилини, вартість хвилини, гривні (гроші), баланс клієнта, адміністратор, мережа, кількість велосипедів, заробіток

Дієслова 
стояти, бути, є (номер), має (ім'я, баланс), взяти, покататись, повернути, коштувати, списати, хоче бачити, заробити

Класи: Клієнт, Велосипед, Станція

Атрибути Велосипеда: номер і тип(звичайний/електричний) 
Атрибути Клієнт:  імя, баланс
Станція: Кількість велосипедів на станції

Крок 3. Кому належить кожне дієслово

Клієнт списує гроші, катається 
Взяти Велосипед (метод)
Брати Велосипед( метод)
Повернути Велосипед (метод)
Списати гроші (метод)
Заробити гроші (функція)
Розрахувати вартість (окрема функція) для станції



Клас ----- Що він ЗНАЄ (атрибути)------ Що він ВМІЄ (методи)


Клас	Bicycle (велосипед)
Що він ЗНАЄ (атрибути)	number: номер велосипеда (ціле число), bike_type: тип, "звичайний" або "електричний"
Що він ВМІЄ (методи)	cost(minutes): повертає вартість поїздки 


Клас	Station (станція прокату)
Що він ЗНАЄ (атрибути)	name: назва станції, bikes: список велосипедів (об'єктів Bicycle), які зараз стоять на станції
Що він ВМІЄ (методи)	take_bike(number): знаходить велосипед за номером, прибирає зі станції й повертає його (або None, якщо такого немає), return_bike(bike): додає велосипед на станцію
bike_count(): повертає кількість велосипедів на станції

Client (клієнт)
Що він ЗНАЄ (атрибути)	name: ім'я клієнта; balance: баланс на рахунку (у грн)
Що він ВМІЄ (методи) списує суму з балансу,  бачити баланс
